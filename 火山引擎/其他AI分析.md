### **1. UI 组件结构拆解（Component Hierarchy）**

整个系统的UI可以分成几个主要区域和组件。通过以下描述，你可以完全清晰地理解每个部分的布局和作用。

#### **整体界面布局**

* **屏幕划分**：整个屏幕分为左右两部分，类似于经典的分屏布局。

  * **左侧区域**：用于用户与AI的交互，用户输入问题，AI根据这些问题生成思考步骤和分析结果。
  * **右侧区域**：显示数据可视化结果，包括图表、表格和业务洞察。

#### **组件分解**

1. **ChatContainer**：这是整个界面的容器，包裹了所有聊天相关的组件。它决定了对话框和输入框的位置。

   * **左侧（对话区）**：这个区域是用来显示用户和AI之间的对话信息。

     * **MessageBubble**（消息气泡）：每一条对话信息都放在“气泡”中。用户的消息气泡较深（例如深蓝色），AI的消息气泡较浅（例如浅灰色），两者通过颜色区分。消息以气泡形式排列，类似聊天应用。
     * **InputBox**（输入框）：用户输入问题的地方。输入框有一个简洁的文本框，文本框下面有一个提交按钮，用户点击按钮后提交问题。
     * **LoadingIndicator**（加载指示器）：当系统正在处理用户输入时，显示一个旋转的加载图标或进度条，告诉用户系统正在思考。

2. **ThoughtSteps**：这是一个非常关键的组件，它负责展示系统分析过程中每一个步骤。每一步骤的执行和展示都是动态的。

   * **Step**（单步组件）：每个“步骤”会逐行展示系统如何处理用户输入的问题。例如，系统可能会先分析问题，生成SQL语句，接着执行SQL查询，最后根据查询结果生成图表。
   * 每个步骤都有一个状态：成功、进行中、或等待。成功的步骤会显示一个绿色勾号，进行中的步骤会显示一个黄色的进度条或旋转标志，等待中的步骤则会显示一个蓝色的加载指示符。

3. **CodePreviewer**：显示SQL查询语句的组件。在此组件中，SQL语句会以高亮的形式呈现，帮助用户理解系统如何执行数据查询。

   * **CodeBlock**：每一段SQL语句会被包裹在代码块内，使用不同颜色区分关键词和变量部分。代码块有自动滚动条，用户可以查看整个SQL语句的详情。

4. **DynamicChart**：负责展示各种图表的组件。根据用户输入的不同，右侧会展示不同类型的图表。

   * **PieChart**（饼图）：用于显示数据的占比，例如显示各个城市的销售占比。
   * **BarChart**（柱状图）：展示销售趋势、各个城市的销售额变化等。
   * **HeatMap**（热力图）：用于展示某些数据的分布密度，比如按地区显示销售密度。
   * **DataCard**：这些是小型的卡片组件，展示一些关键指标，如总销售额、增长率等。

5. **DataTable**：展示具体数据的表格组件。在图表下方，展示查询返回的详细数据。

   * **TableRow**（行组件）：每一行代表一条数据，可能是一个城市或一个时间段的销售数据。
   * **TableCell**（单元格组件）：表格中的每一个单元格，用来显示具体的数值。

6. **LoadingIndicator**（全局加载指示器）：用来全局显示任务进度。当用户的请求需要时间处理时，它会告诉用户“系统正在处理”，避免用户不知所措。

7. **ReportGenerator**（报告生成器）：分析完毕后，生成的报告组件，允许用户查看或者下载分析报告。

   * **ReportPreview**：报告的预览部分，用户可以查看分析结果的汇总。
   * **DownloadButton**：一个下载按钮，允许用户导出生成的报告。

### **2. 交互逻辑与状态管理（Interaction Flow）**

通过以下详细的交互流程，你可以完全理解从用户输入到最终图表展示的过程。

#### **交互流程：**

1. **用户输入问题**

   * 用户在 **InputBox**（输入框）中输入问题，如“2023年各城市销售数据的变化趋势”。
   * 输入框下方的 **LoadingIndicator** 会闪烁，提示系统正在处理用户的问题。

2. **思考中（Thought Steps）**

   * **Step 1**（需求理解）：系统解析用户问题并展示思考步骤：“分析问题：维度——城市，指标——销售数据，时间范围——2023年”。这条信息会逐字打印出来，模拟“打字机效果”，并且逐步显示。此时 **LoadingIndicator** 会显示进度条，表示步骤正在进行。
   * **Step 2**（SQL生成）：系统生成SQL查询语句，显示生成的 SQL 并进行高亮。例如：“生成SQL查询：SELECT city, SUM(sales) FROM sales_data WHERE year=2023 GROUP BY city”。此时 SQL 代码展示在 **CodePreviewer** 组件中。
   * **Step 3**（执行SQL）：系统执行 SQL 查询，**LoadingIndicator** 会再次闪烁并更新进度条，显示数据正在加载中。

3. **图表渲染**

   * **Step 4**：SQL 查询执行完成后，系统根据查询结果生成图表， **DynamicChart** 组件会根据分析的内容展示 **饼图**、**柱状图**、或 **热力图**。

     * 例如，如果用户查询的是“2023年各城市销售趋势”，右侧可能会显示一个柱状图，显示每个城市的销售额。
     * **LoadingIndicator** 会被移除，图表开始渲染。

4. **业务结论**

   * 在图表渲染后，系统会总结出一条业务结论，比如：“2023年某些城市的销售增长显著，特别是城市X。” 这段结论会逐字打印在左侧对话框中。

5. **生成报告**

   * 最后，系统生成报告，用户可以点击 **DownloadButton** 下载报告，或者通过 **ReportPreview** 预览。

#### **思考步骤状态（Thought Steps）**

* **成功状态**：每个步骤完成时，显示一个绿色的勾号，表示该步骤已成功完成。
* **进行中状态**：步骤正在进行时，显示一个黄色的进度条，表示系统正在处理。
* **等待中状态**：步骤在等待某些操作或数据时，显示一个蓝色的等待图标。

### **3. 内容逆向提取（数据与代码）**

从截图和视频中提取出几个具体的案例，详细描述它们的内容和步骤。

#### **案例 1：**

1. **用户提问**：“2023年各城市销售数据变化趋势”

2. **系统思考链（Thought Steps）**：

   * 步骤1：理解问题 → 维度：城市、指标：销售数据、时间：2023年。
   * 步骤2：生成SQL查询语句。
   * 步骤3：执行SQL查询并加载数据。
   * 步骤4：生成图表，展示各城市的销售趋势。

3. **SQL语句**：

```sql
-- 查询2023年各城市的销售数据
SELECT city, SUM(sales) AS total_sales
FROM sales_data
WHERE year = 2023
GROUP BY city
```

4. **图表类型及核心指标数据**：

   * **饼图**：展示不同城市销售额的占比。
   * **柱状图**：展示各城市2023年销售趋势，X轴是城市，Y轴是销售额。
   * **核心指标**：每个城市的销售额和增长趋势。

### **4. 视觉风格与技术栈建议（Design System）**

#### **视觉风格分析**

* **配色方案**：

  * 背景色：浅灰色背景 (#F5F6F7)，避免视觉疲劳。
  * 文字色：深灰色或黑色文字 (#333333)，确保良好的可读性。
  * 主色调：蓝色（#007BFF），用于突出图表、按钮和交互元素。
  * 按钮、图表等交互元素使用蓝色或浅蓝色作为强调色。

* **间距感与阴影**：

  * 界面中元素间距较大，确保每个组件的独立性和清晰性。
  * 阴影：轻微的阴影（例如 0px 4px 12px rgba(0, 0, 0, 0.1)）用于分隔组件，但不影响界面的简洁性。

* **圆角设计**：所有对话框、按钮、输入框等元素均采用圆角设计，半径一般为4px。

#### **技术栈建议**

* **React/Vue**：用于构建组件化的前端界面，React 推荐使用功能组件，Vue 可以使用单文件组件来实现。
* **Ant Design**：提供完整的UI组件库，特别适合用于开发企业级应用。
* **ECharts**：用于数据可视化，生成各类图表。
* **TailwindCSS**：用于快速开发响应式、简洁的UI。
* **Redux/Context API**：用于全局状态管理，尤其是在多步分析过程中的数据流动。

### **5. 复杂功能点识别**

#### **复杂功能点**

* **多轮对话**：在分析过程中，系统会逐步显示每个分析步骤，形成“多轮”交互。
* **结果纠错**：如果用户提供了错误的输入或系统无法解析，系统应能提供纠错建议。
* **指标解释**：每个图表或SQL查询后，系统会提供数据洞察或指标解释。
* **图表联动**：多个图表（如柱状图、热力图）会根据用户的提问实时联动展示。
