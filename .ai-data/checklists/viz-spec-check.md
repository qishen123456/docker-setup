# 可视化规范校验清单

> 可视化设计师在 Phase 4 产出前逐项检查。

## 图表选型

- [ ] **时序数据**：折线图（趋势）/ 面积图（累计）— 禁用饼图
- [ ] **占比数据**：饼图（≤5类）/ 环形图（>5类）/ 100%堆叠柱 — 禁用折线
- [ ] **对比数据**：柱状图（分类对比）/ 分组柱（多维度对比）
- [ ] **分布数据**：箱线图（分布）/ 散点图（双变量关系）
- [ ] **排行数据**：横向柱状图（Top N）/ 漏斗图（转化漏斗）

## 视觉规范

- [ ] 配色使用 SmartAsk 前端既有的 ECharts 主题，不硬编码颜色值
- [ ] 字号统一：标题 14px / 轴标签 12px / 图例 11px
- [ ] 图例位置不遮挡数据
- [ ] 坐标轴有单位标注（元/次/% 等）

## 交互状态

- [ ] hover 有 tooltip 提示
- [ ] 数据加载中有 loading 态
- [ ] 空数据有占位提示
- [ ] 大数据集有分页或滚动

## 无障碍

- [ ] 不仅靠颜色区分数据系列（搭配线型/图案/标签）
- [ ] 文字对比度 >= 4.5:1
- [ ] 图表有 title 和 desc 用于屏幕阅读器
