# 分析严谨性校验清单

> 各分析师在 Phase 2 产出前逐项检查。主理人合成时复核。

## 方法标注

- [ ] 每项分析结论标注所用方法（如"IQR 离群检测""帕累托 80/20"）
- [ ] 统计窗口已标注（如"近 30 天""Q1 vs Q2"）
- [ ] 对比基准已标注（如"同比/环比/行业均值"）
- [ ] 样本量已标注（n=XXX），样本 < 30 时标注"小样本，结论仅供参考"

## 交叉验证

- [ ] 趋势结论与结构结论无矛盾（如有，矛盾点已标注）
- [ ] 异常检测结果与趋势结论交叉印证（异常点是否影响趋势判断）
- [ ] 多视角矛盾点已由主理人裁决，裁决理由已记录

## 可溯源性

- [ ] 每条结论可追溯到具体数据行/聚合结果
- [ ] 无"凭空结论"（无数据支撑的推断需标注为"推测"）
- [ ] 引用外部数据（行业/竞品）时标注来源和时间

## 数据诚实

- [ ] 无法判断的地方标"待确认"，不编造数字
- [ ] 数据质量问题已上报，不在脏数据上做分析
- [ ] 结论局限性已标注（如"仅覆盖华东区域，不代表全国"）

## 行动导向

- [ ] 每个分析章节末尾有"建议下一步"
- [ ] 建议是可执行的（有具体动作），不是"需要进一步关注"
- [ ] 建议优先级已标注（高/中/低）
