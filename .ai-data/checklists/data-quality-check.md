# 数据质量校验清单

> 数据工程师在 Phase 1 产出前逐项检查。命中 CRITICAL 必须修复后才能进入 Phase 2。

## CRITICAL 级（必须修复）

- [ ] **完整性**：关键字段无 NULL/空值，非关键字段缺失率 < 5%
- [ ] **一致性**：同一字段在不同数据源中的类型和含义一致
- [ ] **唯一性**：主键无重复，业务唯一标识无冲突
- [ ] **时效性**：数据时间范围覆盖分析需求，无断档

## WARN 级（建议修复）

- [ ] **分布检查**：数值字段无异常集中值（如 99% 为 0），若有需标注
- [ ] **编码统一**：分类字段编码一致（如 M/F 与 男/女 不混用）
- [ ] **精度保持**：聚合计算未丢失精度（如百分比保留两位小数）
- [ ] **口径标注**：每个字段附口径说明（计算公式/统计窗口/数据来源）

## INFO 级（记录即可）

- [ ] 数据行数与预期量级匹配（差异 > 20% 需说明原因）
- [ ] 已知的数据延迟（如 T+1 更新）已在报告中标注
- [ ] 数据源版本号已记录
