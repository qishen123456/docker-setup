## 簇 1：ds=3 事业部级聚合断链（P0，真实用户必踩）

**现象**：「商用事业部 + 具体指标词（开单金额/达成率/年度开单金额/回款）」稳定 0 行（3 跑 3 漏，非抖动）；泛词"业绩"正常（走下级罗列兜底 8 行）；消费者/电商事业部 + 指标正常。

**根因（双侧实锤，无需再验）**：
- 第三方实测 + DB 复验一致：`angel_group_data` 表 `fields->>'事业部'='商用事业部'` 有 **116 行**（年度开单金额样本 2.14 亿 / 3920 万 / 3753 万），而 `fields->>'节点名称'` 为 **0 行**
- **表中不存在"节点名称"字段**，节点在"事业部"字段——查询用了错误字段名，稳定 0 行
- 数据有、字段错：**SQL/字段映射层 bug**

**修复方向**：定位生成该 SQL 的字段映射来源（数据集配置 or 硬编码映射），`节点名称` → `事业部`。修复前**先全仓 grep `fields->>'节点名称'`** 查波及面。

**验收用例**：`p1_targeted_cases.json` 中 3 道 `known_defect=sql-field-mapping` 题（修复后摘掉 known_defect 标签，跑 `p1_gate_check.py` 应全 PASS）。

**关联**：商用事业部回款类（回款金额/回款达成率 0 行，Trae 批次3 GG 类 5 题）疑似同簇，修复时一并验证。

## 簇 2：阈值筛选 SQL 疑单位错（P1）

**验收**：修复后 4 道原题复跑应有行或走合理澄清。
