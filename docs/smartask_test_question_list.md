| **Agent2** | 意图（排名/筛选/总览/下钻/对比/极值/指定名次）是否解析正确；SQL 是否命中正确表/字段/聚合/排序/过滤 |

| **Agent4** | 卡片标题是否贴合问题；摘要是否针对答案；KPI/排名/筛选/下钻/对比卡片是否按场景展示；避免模板化文案；单位与标签语义一致 |
