## 4. 评估方法与回归门槛（建议）

- **时间锚点硬测试**：在测试桩里把「当前日期」设为非 2026（如 2027-03-01），问「今年/去年/上月」，断言生成 SQL 使用注入年份，不得出现与运行时不相关的硬编码年份。
- **防臆造测试**：问涉及不存在字段/表的问题，断言不出现臆造表名或字段名。
- **关联语义测试**：问跨编码体系关联（如 `project_code`），断言走了映射表而非同名直接 JOIN。
- **可视化触发测试**：≥3 类别对比必须调用 `generate_visualization`；单值可不调用。
- **Copilot 契约测试**：生成的 payload 必须 `json.loads` 通过且满足 `PUT /api/bookshelves/datasets/<id>/full` 校验（≥1 LLD、≥1 schema、≥3 Golden SQL、4 个 agent prompt 全配齐）。
- **回归门槛**：上述用例 100% 通过，且相对 `batch_test_questions.py` 既有基线，准确率不下降。

详见配套文档 `提示词测试用例集.md`。
