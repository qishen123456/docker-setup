# 飞书企业级集成方案

> ⚠️ 本文档为实施计划，仅供评估，未修改任何代码

## 一、飞书免登 (SSO) — OAuth 2.0

### 1.1 整体架构

```
用户浏览器 → Nginx(内网) → 飞书开放平台(公网回调) → Nginx反代 → 后端/api/auth/feishu/callback
```

### 1.2 OAuth 2.0 流程

| 步骤 | 描述 |
|------|------|
| 1 | 前端跳转至飞书授权页 `https://open.feishu.cn/open-apis/authen/v1/authorize?app_id=xxx&redirect_uri=xxx` |
| 2 | 用户在飞书内授权 |
| 3 | 飞书回调 `redirect_uri` 携带 `code` |
| 4 | 后端用 `code` 换取 `access_token` + `user_info` |
| 5 | 后端签发 JWT，写入 HttpOnly Cookie |

### 1.3 Nginx 反向代理解决内网回调

**问题**：飞书回调需公网可达，但系统部署在内网。

**方案A — 边缘节点转发**：
```nginx
# 公网边缘 Nginx (有公网IP)
server {
    listen 443 ssl;
    server_name feishu-callback.your-domain.com;

    location /api/auth/feishu/callback {
        proxy_pass http://内网IP:5002;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

**方案B — 飞书自建应用 + 内网穿透**：
- 使用 frp/ngrok 将内网 5002 端口映射到公网
- `redirect_uri` 配为穿透后的公网地址

**方案C — 飞书自建应用商店内网部署**：
- 飞书企业版支持「内网部署」模式
- 回调地址可配为内网地址，飞书客户端直接访问

### 1.4 后端实现要点

```
backend/controllers/auth.py  (新增)
├── GET  /api/auth/feishu/login     → 生成授权URL并重定向
├── GET  /api/auth/feishu/callback  → 用code换token, 创建/更新用户, 签发JWT
├── GET  /api/auth/me               → 返回当前用户信息
└── POST /api/auth/logout           → 清除Cookie
```

## 二、权限路由分流

### 2.1 角色定义

| 角色 | 权限 | 可见菜单 |
|------|------|----------|
| `leader` | 仅问数 | 问数会话 |
| `admin` | 全功能 | 全部菜单 |
| `viewer` | 只读问数 | 问数会话(只读) |

### 2.2 实现方案

**后端**：
- `bs_users` 表增加 `role` 字段 (默认 `leader`)
- JWT payload 含 `{ user_id, role, department }`
- API 中间件校验角色权限

**前端**：
```javascript
// router/index.js — 路由 meta 标注
{ path: '/smart-ask', meta: { roles: ['leader', 'admin'] } },
{ path: '/ai-models', meta: { roles: ['admin'] } },
{ path: '/datasets',  meta: { roles: ['admin'] } },
// ...

// 全局路由守卫
router.beforeEach((to) => {
  const user = useAuth()
  if (to.meta.roles && !to.meta.roles.includes(user.role)) {
    return '/smart-ask' // 无权限则回到问数页
  }
})
```

**App.vue 侧边栏**：
```html
<el-menu-item v-if="hasRole('admin')" index="/ai-models">
```

### 2.3 领导极简视图

- 隐藏侧边栏所有配置项，仅保留「问数会话」
- 隐藏顶部栏的技术信息（后端状态等）
- 自动折叠侧边栏，最大化问数区域

## 三、消息推送闭环

### 3.1 链路设计

```
系统完成分析 → 后端生成结果 → 调用飞书机器人API → 推送交互式卡片
    ↓
卡片含「查看详情」按钮 → 携带 query_id → 跳转系统结果页
    ↓
/smart-ask?restore=<query_id> → 前端自动恢复历史会话
```

### 3.2 飞书机器人推送

```python
# backend/feishu_bot.py (新增)

    card = {
        "config": {"wide_screen_mode": True},

        },
        "elements": [
            {"tag": "markdown", "content": summary[:200]},
            {"tag": "action", "actions": [{
                "tag": "button",
```
