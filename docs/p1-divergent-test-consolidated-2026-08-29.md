## 4. P1 动工输入清单（合并去重后按优先级）

### 6.5 教科书题漏网定位（2026-08-29 补，3+5 题实跑）

「商用事业部年度开单金额」3 跑 3 漏（**稳定复现，非抖动**），定向探测 5 题钉死边界：

| 题 | 结果 |
|---|---|
| 商用事业部年度开单金额 ×3 | ZERO_LEAK ×3（稳定） |
| 商用事业部开单金额 | ZERO_LEAK |
| 商用事业部达成率 | ZERO_LEAK |
| 商用事业部的**业绩** | DIRECT_OK rows=8（泛词"业绩"能答） |
| 消费者事业部年度开单金额（对照） | DIRECT_OK rows=14 |
