# SmartAsk 基础版智能问数 — 演讲材料说明

本目录包含 SmartAsk 基础版智能问数的多版本演讲材料，适用于不同汇报场景（技术评审、业务汇报、高层汇报、客户演示等）。

## 文件清单

| 文件 | 用途 | 建议场景 |
|---|---|---|
| `基础版智能问数PPT大纲.md` | 18 页 PPT 内容大纲 | 通用汇报，技术/业务双修 |
| `基础版智能问数PPT大纲_Word导入版.xml` | Word 2003 XML 格式 | PowerPoint「幻灯片从大纲」导入 |
| `基础版智能问数PPT大纲_文本导入版.txt` | Tab 缩进文本版 | XML 导入失败时的备选 |
| `基础版智能问数演讲稿.md` | 18 页完整演讲稿，约 4500 字 | 正式评审，18–22 分钟 |
| `基础版智能问数演讲稿_10分钟版.md` | 10 分钟压缩版 | 时间紧张的汇报 |
| `基础版智能问数演讲稿_安吉尔场景版.md` | 家电/净水行业场景定制版 | 面向安吉尔及同类企业的业务汇报 |
| `基础版智能问数Q&A预案.md` | 20 个专业 Q&A | 答疑准备 |

## 快速开始

### 1. 生成 PPT

推荐使用 `基础版智能问数PPT大纲_Word导入版.xml`：

1. 打开 PowerPoint
2. 新建空白演示文稿
3. 点击「开始」→「新建幻灯片」→「幻灯片（从大纲）」
4. 选择 `基础版智能问数PPT大纲_Word导入版.xml`
5. PowerPoint 会自动生成 18 页幻灯片
6. 根据生成的内容套用企业模板、补充图表和截图

> 如果 XML 导入失败，可使用 `基础版智能问数PPT大纲_文本导入版.txt` 重试。

### 2. 选择演讲稿

| 场景 | 推荐文件 |
|---|---|
| 正式评审/技术汇报 | `基础版智能问数演讲稿.md` |
| 时间紧张/高层快速汇报 | `基础版智能问数演讲稿_10分钟版.md` |
| 面向安吉尔业务用户/客户演示 | `基础版智能问数演讲稿_安吉尔场景版.md` |

### 3. 准备 Q&A

正式汇报前请通读 `基础版智能问数Q&A预案.md`，重点准备：

- 准确率如何保障
- 与 BI 的关系
- 数据安全与权限
- 部署周期与落地方式
- 后续演进路线

## 内容定位

- **演讲主题**：SmartAsk 基础版智能问数（业务问数版）
- **覆盖能力**：约占完整版 30%，聚焦自然语言问数的最小闭环
- **核心卖点**：可信回答、四层 Agent 架构、SQL 三层稳定策略、报告契约、行级权限、Autonomous BI 演进
- **目标受众**：业务管理者、数据团队、IT 负责人、客户决策者

## 注意事项

1. PPT 导入后需要手动补充品牌模板、配色、图表、截图
2. 安吉尔场景版中的组织层级、业务术语可根据实际客户调整
3. 演讲稿中的时间标记为建议值，现场可灵活调整
4. 基础版不展开进阶 Skill、LangChain/MCP、系统控制台等内容，仅在演进路线中提及
