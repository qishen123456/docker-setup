# ANGEL 品牌视觉重构计划

> 项目：智能问数 / 经营分析工作台  
> 目标：只改 UI 视觉，不改问数流程、业务逻辑、接口、路由、状态管理和 DOM 结构  
> 风格依据：以安吉尔官网气质为准，参考当前截图中的黑白红秩序感，但降低黑色纯度，增加高级透明层次

## 1. 现状判断

当前项目的核心问题不是“红色不够”，而是视觉秩序偏硬，黑白红关系没有被统一管理。

1. 左右两侧黑边过重，尤其是侧边栏与顶栏的纯黑面，压迫感明显。
2. 红色使用位置偏碎，既承担品牌强调，又承担状态提示，还承担局部装饰，视觉重心不稳定。
3. 页面中大量白卡片直接贴在纯白/纯黑环境里，层级有，但质感不够。
4. 问数页、登录页、控制台页的风格各自为战，缺少同一套品牌语言。
5. 现有界面更像“功能壳”，还没进入“品牌工作台”的完成态。

## 2. 目标风格

目标不是做成“更红”，而是做成“更像安吉尔官网感的企业级工作台”。

品牌关键词：
- 净水科技
- 专业
- 纯净
- 稳重
- 高级
- 克制
- 可信赖

视觉原则：
- 大面积白 / 浅灰作为主底
- 深灰黑作为结构色，不用死黑
- 品牌红只做点睛
- 绿色只留给在线 / 成功
- 禁止蓝绿科技风成为主交互色
- 禁止高饱和渐变、霓虹感、厚重阴影

## 3. 黑色调整策略

你提到“黑色太黑了”，这个判断是对的。建议从“纯黑压顶”改成“深灰黑透明层”。

推荐方向：
- 顶栏主底从 `#1A1A1A` 调整为 `rgba(20, 20, 20, 0.92)`
- 侧栏主底从纯黑调整为 `rgba(24, 24, 24, 0.90)`
- 浮层、卡片、弹层边缘保留轻微玻璃感，加入 `backdrop-filter`
- 阴影改为低对比、短扩散，避免厚重黑影

建议的黑系 token：
```css
--brand-black: rgba(20, 20, 20, 0.92);
--brand-black-strong: rgba(20, 20, 20, 0.96);
--brand-black-soft: rgba(20, 20, 20, 0.82);
--brand-surface-dark: rgba(28, 28, 28, 0.88);
--brand-overlay: rgba(255, 255, 255, 0.72);
```

## 4. 视觉改造范围

只改这些：
- 颜色
- 字体
- 边框
- 阴影
- 圆角
- 背景
- hover / active / focus
- logo / favicon
- 图标皮肤
- 品牌文案
- 空态视觉

不改这些：
- 业务流程
- 接口
- 路由
- 状态管理
- DOM 结构
- 页面布局

## 5. 分层改造计划

### Phase 1 全局 Token

先把全站视觉基座收口到一个主题文件里，统一引用。

重点建立：
- 品牌红
- 深灰黑
- 文本灰阶
- 浅灰背景
- 边框灰阶
- 状态色
- 统一阴影
- 统一圆角

目标是让 Element Plus、页面自定义组件、浮层、表格、按钮都从同一套 token 读取。

### Phase 2 壳层重构

优先处理最刺眼的地方：

- 左侧导航栏
- 顶栏
- 历史分析区
- 用户菜单
- 在线状态
- 页面外层背景

这里要解决两个问题：
- 去掉“断层黑边”的生硬感
- 把页面从黑白对冲，调整为深灰黑 + 白 + 红点睛

### Phase 3 智能问数页

这是整个项目的视觉主场，优先级最高。

重点处理：
- 欢迎首屏
- 会话头部
- 对话气泡
- 思考卡
- 执行轨迹
- 结果摘要
- 右侧详情面板
- 底部输入器

这一页要从“工具拼装感”变成“统一的品牌工作台感”。

### Phase 4 登录页

登录页要更克制，不做营销海报感。

方向：
- 白底或极浅灰底
- 标题更稳重
- 品牌红只用于 logo 点睛和主按钮
- 去掉过强的渐变和厚阴影

### Phase 5 管理页统一

逐页修正以下页面的颜色与组件皮肤：
- 系统控制台
- 飞书同步
- 数据资产管理
- 模型服务配置
- 报告模板配置
- 进阶能力中心
- 其他配置页

原则是统一，不重做布局。

## 7. 关键视觉落点

1. 侧栏：从纯黑改为半透明深灰黑，保留品牌感，但减轻压迫。
2. 顶栏：改成有一点通透感的深灰黑，不要像一整块墨块。
3. 卡片：统一白底、浅灰边、低阴影，少用硬边黑框。
4. 主按钮：红色只用于关键动作，其他按钮尽量中性化。
5. 激活态：红色做细线、浅底、局部强调，不铺大面积红。
6. 状态色：绿色只给成功和在线，别抢主视觉。
7. 空态：用更轻的插画感和留白，避免页面发空。

## 8. 实施顺序

1. 先落 `angel-theme.css` 统一 token。
2. 再改 `App.vue`，解决整体壳层和黑边问题。
3. 再改 `SmartAsk.vue` 和 `components/smartask/*`。
4. 再改 `AuthLogin.vue`。
5. 最后补各管理页。

## 9. 验收标准

改完后应满足：
- 页面不再有生硬的纯黑断层
- 黑色是深灰黑透明层，不是压顶黑
- 红色只在关键点出现
- 所有页面风格统一
- 业务流程、交互、路由完全不变
- 视觉像一个完整品牌系统，而不是局部换皮
