## 3. P1 发现清单（按优先级，全部有实测题号证据）

### 🔴 P0 级

1. **ds=3 商用「回款」指标事业部级聚合断链**：批次1「进账多少」、批次2「回款多少/收了多少款」、批次3「回款金额/回款达成率」共 **5 题全 0 行**；但「东部分公司回款」「北部分公司回款」能答出 → 疑似事业部级聚合 SQL 或回款字段映射问题，不是理解层问题
2. **方向口误词表仅覆盖"最好不"**：最差/最高/最低/最多/最少+不的 5 种形态 **10 题全漏**（批次1×3、批次2×10 证据）；合法对照（最好/最不好）零误拦 ✅
3. **阈值筛选 SQL 疑单位错误**：「达成率低于八成」「达成率百分之五十以下」「达成没及格」「没完成任务」**4 题全 0 行**——疑似 0.8 vs 80 量级错
4. **诊断卡候选文本污染**：「请列示达成率未达百分之百的代表处清单」→ 候选输出"达成率未达**播**分之百"（"达播"节点名注入）；「东北三省」→ 候选"东北部分公司"（书架上不存在的节点）——**zero_row_diagnosis_a 的候选生成会编造/污染文本**

### 🟡 P1 级

5. **错字卡同人不同命**：朱伟锋中/朱卫峰漏、陈晓斌中/陈小彬漏（各 1 字差），窗口/锚定规则不一致；朱伟峰甚至走了 source=null 的另一条澄清通道（与 typo_fastpath 双通道并存）
6. **方向卡不级联修错字**：「迟浩最好不的单子」方向卡命中，但候选句仍是"迟浩…"（错字原样保留）
7. **平台别名表不全**：京东商城/某宝/某东/TMALL/tmall 无别名映射（错路由或确认卡兜底）；「抖音dy直播」错路由 ds=3
8. **地域→书架节点无映射**：华中/沿海/内陆/两广/东北三省 共 **5 题 0 行或误导候选**；西南走了 source=null 通道给了正确候选（云贵渝/川藏）✅ 说明能力有、通道分裂
9. **跨集超复合**：「商用和电商各自的销冠」路由正确（ds=3,62）但 0 行——跨集多主体 SQL 生成短板
10. **中段语义无支持**：「表现还行」「业绩一般」「刚好完成任务」无法映射到区间筛选
