## 本轮未完成项

### Docker daemon 未就绪

执行：

```powershell
docker compose ps
```

结果：失败。

原因：Docker Desktop Linux Engine 未启动或 daemon 未就绪。

错误类型：

```text
open //./pipe/dockerDesktopLinuxEngine: The system cannot find the file specified
```

处理建议：

1. 手动打开 Docker Desktop。
2. 等待 Docker Desktop 状态稳定。
3. 再执行：

```powershell
.\deploy.ps1 -RunTests
```

如需完整 AI 流式问数测试，再执行：

```powershell
.\deploy.ps1 -RunTests -RunStreamTests
```
