# SmartAsk 智能问数 2 分钟演示视频 · 分镜脚本

> 用途：项目展示视频（约 120 秒）
> 主线：「总览 → 下钻 → 根因」问数旅程 + 能力矩阵 + 系统管理
> 形式：屏幕录制 + 旁白 + 花字标注（推荐 剪映：自动字幕 + 局部放大）

---

## 一、整体结构（120 秒分配）

| 段落 | 时长 | 内容 |
|---|---|---|
| 开场钩子 | 0:00–0:12 | 痛点对比：传统取数 vs SmartAsk |
| 主线演示 | 0:12–0:55 | 总览 → 追问下钻 → 根因分析（核心，占 1/3 时长） |
| 能力矩阵 | 0:55–1:35 | 对比 / 排名 / 筛选 / 歧义确认（每个 8-10 秒快节奏） |
| 系统管理 | 1:35–1:50 | 管理后台快速扫过 |
| 收尾 | 1:50–2:00 | 价值总结 + slogan |

---

## 二、逐镜头脚本

### 段落 1：开场钩子（0:00–0:12）

**镜头 1**（0:00–0:06）
- 画面：黑底白字快闪，或录屏"翻 Excel / 找 IT 提数"的素材
- 旁白：「业务问一个数，传统方式要多久？半天？一天？」
- 花字：`问个数 = 提工单 + 等排期？`

**镜头 2**（0:06–0:12）
- 画面：SmartAsk 首页淡入，光标落到输入框
- 旁白：「用 SmartAsk，一句话，十秒钟，直接问。」
- 花字：`SmartAsk 智能问数`

### 段落 2：主线演示——总览 → 下钻 → 根因（0:12–0:55）

> 这一段是灵魂，节奏放慢，让观众看清"追问"是怎么不用重复说背景的。

**镜头 3**（0:12–0:24）总览
- 画面：输入「商用分公司的业绩」→ 发送 → 报告卡片展开（KPI + 表格 + 分析）
- 旁白：「比如我想看商用条线的盘子——直接问。系统返回整体达成率、各分公司明细，还有一段经营分析。」
- 花字：`① 总览：一句话出报告`
- 录制技巧：发送后等结果时用 1.5 倍速，报告出现时恢复常速并给 KPI 卡一个局部放大

**镜头 4**（0:24–0:38）追问下钻（重点）
- 画面：不清空、不换页，直接在同一会话里追问「东部分公司呢」→ 结果切换；再追问「河南代表处的业绩」→ 定位到代表处明细
- 旁白：「看到东部偏弱，直接追问——不用说'商用事业部的东部分公司'，系统记得我们聊到哪了。再往下钻一层到河南代表处，哪个人、差多少，一目了然。」
- 花字：`② 追问下钻：带记忆的对话式分析`
- 录制技巧：追问时给"输入框没变、上下文还在"一个特写，这是和 BI 工具的差异化

**镜头 5**（0:38–0:55）根因分析
- 画面：报告里的 AI 分析段落滚动展示（落后节点、缺口金额、建议）
- 旁白：「系统不只是给数，还会告诉你：是哪个节点拖了后腿、缺口多大、下一步该盯谁。从总览到根因，三次对话，不到一分钟。」
- 花字：`③ 根因定位：数据 + 解读 + 建议`

### 段落 3：能力矩阵（0:55–1:35）

> 快节奏，每个能力 8-10 秒：半秒提问画面 → 结果 → 花字盖章。建议用同一版式，形成"唰唰唰"的节奏感。

**镜头 6**（0:55–1:05）对比
- 提问：「京东直营和天猫直营对比」
- 画面：对比表 + 对标分析（达成率 30.42% vs 19.09%）
- 旁白：「对比——两个渠道谁强，差距多少，直接对标。」
- 花字：`对比`

**镜头 7**（1:05–1:15）排名
- 提问：「业绩前三的分公司」
- 画面：排名表，前三名高亮
- 旁白：「排名——前三名是谁，垫底的是谁，脱口而出。」
- 花字：`排名`

**镜头 8**（1:15–1:25）筛选
- 提问：「达成率大于 50% 的分公司有哪些」
- 画面：过滤后的列表
- 旁白：「筛选——条件随便说，大于、小于、区间，都听得懂。」
- 花字：`筛选`

**镜头 9**（1:25–1:35）歧义多轮确认（差异化亮点）
- 提问：「业绩咋样了」→ 系统弹数据集确认卡片（消费者/商用/电商三选一）→ 点选后出结果
- 旁白：「问得有歧义？它不瞎猜——反过来问你一句，确认了再查。宁可多问一句，不给你一个错的数。」
- 花字：`歧义确认：不瞎猜`
- 录制技巧：这是体现"企业级严谨"的镜头，给确认卡片一个停顿

### 段落 4：系统管理（1:35–1:50）

**镜头 10**（1:35–1:50）
- 画面：侧边栏展开管理菜单，快速扫过：AI 模型管理（通道/测通）、数据集管理、权限/角色、飞书同步
- 旁白：「后台管理也配齐了：大模型通道在线测通、数据集策略、按角色的数据权限、飞书多维表自动同步——IT 不用写一行代码。」
- 花字：`系统管理：模型 · 数据 · 权限`
- 录制技巧：每个页面停 2-3 秒，用 1.2 倍速串起来；模型下拉的"测通"状态值得一个特写

### 段落 5：收尾（1:50–2:00）

**镜头 11**（1:50–2:00）
- 画面：回到问数主页，logo/slogan 淡入
- 旁白：「SmartAsk——让每一个人，用自己的话，问自己的数据。」
- 花字：`SmartAsk · 一句话问数`

## 三、录制与剪辑建议

1. **录屏**：1920×1080，浏览器隐藏书签栏，页面缩放 90%（字更大更清楚）；用 OBS 或剪映录屏
2. **等待处理**：问数等待过程统一加速 1.5–2 倍，结果出现恢复常速——观众只对"结果"有耐心
3. **局部放大**：KPI 数字、追问输入框、确认卡片三处做放大动画（剪映"关键帧+放大"即可）
4. **字幕**：旁白用剪映自动字幕，花字统一用一个颜色（建议用系统主色），字号大、出现位置固定在顶部
5. **背景音乐**：选科技感轻音乐，音量压到旁白的 20% 以下
6. **数据准备**：录制前把要问的 5 个问题先手动跑一遍预热（避免录制时撞 LLM 抖动），案例顺序照脚本走

## 四、一句话主线（防跑题）

整片只讲一件事：**"像聊天一样问数据，而且越问越深"**。能力矩阵是佐证，系统管理是兜底，别喧宾夺主。
