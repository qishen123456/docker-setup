## 三、主要问题汇总

| 问题 | 现象 | 建议 |
|---|---|---|
| 线下业务开单金额排名前3的分公司 | 返回的是城市分公司前3（广州/深圳/粤西），不是分公司前3 | 明确 `target_level=分公司` 时，排序和截断应在分公司层级执行 |
| 线下业务完成率最高的城市分公司 | 标题和排序指标都变成“线下业务开单金额”，未按达成率排序 | 识别“完成率/达成率”作为排序指标，而不是默认开单金额 |
| 燃气定制任务达成率最低的分公司 | 按燃气定制开单金额排序，未按达成率排序 | 业务线+达成率组合问法应优先匹配达成率指标 |
| 分公司中线下任务缺口最大的是哪个 | 按线下开单金额降序返回，标题也变成“排名前3” | “缺口最大”应使用剩余任务金额/缺口作为排序指标 |

## 四、结论

- 单点“最高/最低”问法（无论是否带“哪个”）已能正确返回唯一答案并展示下级明细。
- 对比、过滤、下钻类基础问法整体可用。
- 需要继续优化的是**排序指标识别**和**目标层级保持**，特别是在带数量词（前3/后3）和“达成率/缺口”等度量词的复杂问法中。
