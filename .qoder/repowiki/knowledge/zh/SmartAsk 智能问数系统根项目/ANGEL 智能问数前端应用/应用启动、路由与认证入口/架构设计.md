模块由五个文件构成清晰的职责分层：
- `main.js` 是应用入口，创建 Vue 实例并全局注册 Element Plus（含中文语言包与全部图标）、引入样式、挂载 router，并在路由就绪后调用 `initFeishuEnv` 初始化飞书环境。
- `router/index.js` 集中定义所有路由，使用 `viewLoaders` 映射实现按需懒加载，并通过 `preloadRouteComponents` 暴露预取接口；`afterEach` 钩子统一设置文档标题。
- `App.vue` 作为根组件承担应用外壳（侧边栏、顶栏、历史面板、管理员悬浮按钮等），通过 `authReady`/`authUser` 状态驱动登录态分支渲染：未就绪时显示 loading，未登录时渲染 `AuthLogin`，已登录则进入 `el-container` 主布局并缓存页面组件。
- `auth/AuthLogin.vue` 提供两种登录方式：表单提交走 `passwordLogin` + `setAuthToken`，飞书登录走 `getFeishuLoginUrl` 重定向；登录成功后通过 `@authenticated` 事件将用户信息回传给 App。
- `views/AuthCallback.vue` 处理 `/auth/callback` 路由，从 query 中取 token 调用 `setAuthToken` 后跳转至 `/smart-ask`。
依赖方向单向：App → AuthLogin / router → views，认证相关逻辑不反向依赖业务视图。
