本模块由四个独立的 Vue 单文件组件组成，均位于 `frontend/src/views/` 下，各自承担一个完整的前端功能域：
- `FeishuSync.vue`：飞书同步工作台，通过 `../api/index.js` 调用后端同步配置 CRUD、连接测试、Schema 预览、日志聚合等接口，使用 `el-tabs` 组织全局调度、统一日志、任务编排三个子面板，并通过 `useFeatureFlags` 控制按钮可见性。
- `RuntimeMigration.vue`：运行态迁移工作区，支持导出/导入 JSON 包、预检影响范围、自动备份与回滚，所有操作受 `runtime_*` 系列 feature flag 控制。
- `AdvancedCapabilities.vue`：进阶能力中心，管理 Skill 列表、MCP 服务、SQL Server 工具及执行策略，通过 `getAskFlowConfig` 与问数流程控制器联动实现灰度进入。
- `SqlDebug.vue`：SQL 调试台，提供直接 SQL 查询和自然语言转 SQL 两种模式，结果以自定义 `ResultPanel` 组件渲染，状态持久化到 `localStorage`。

依赖方向单一：各组件仅依赖 `../api/index.js` 的 HTTP 封装和 `../state/featureFlags.js` 的功能开关，彼此之间无相互引用，属于并列的叶子视图。
