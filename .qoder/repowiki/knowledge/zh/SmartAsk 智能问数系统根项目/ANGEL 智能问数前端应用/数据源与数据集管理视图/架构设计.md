四个 Vue 单文件组件均位于 `frontend/src/views/` 下，采用 Composition API `<script setup>` 风格，通过 `../api/index.js` 调用后端 REST 接口，通过 `../state/featureFlags.js` 的 `useFeatureFlags()` 组合式函数获取功能开关控制 UI 可见性。
- `Databases.vue`：独立的数据源 CRUD + 连通性测试，使用 Element Plus 表格+弹窗表单，按数据库类型（sqlite/mysql/postgresql/sqlserver）动态渲染字段。
- `DatasetManagement.vue`：最复杂的视图，左侧数据集列表 + 右侧多标签页编辑器（常见问题、回归题集、同义词、LLD、数据字典、DDL+表关联、Golden SQL、Agent 提示片段、外部配置、数据转换），支持“从提示词生成数据集”的长耗时异步流程（带进度条与阶段指示器）。
- `DatasetReportConfig.vue`：报告配置双栏布局（左侧数据集列表 + 右侧可视化/JSON 双模式编辑器），维护列映射、指标定义、信号灯规则、意图策略等 JSON 结构。
- `Bookshelves.vue`：轻量版书架维护入口，结构与 DatasetManagement 类似但更简洁，作为历史兼容入口保留。
依赖方向单向：views → api/index.js → 后端；所有权限判断统一走 `isFeatureEnabled('xxx')`，无跨 view 状态共享。
