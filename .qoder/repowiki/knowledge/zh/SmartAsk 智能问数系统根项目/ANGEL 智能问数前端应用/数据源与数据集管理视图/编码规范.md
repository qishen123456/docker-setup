- 所有视图通过 `useFeatureFlags()` 的 `isFeatureEnabled(key)` 控制按钮/区域显示，feature key 命名遵循 `{模块}_{操作}` 格式（如 `dataset_question_create`、`datasource_test`、`report_template_edit`）。
- 数据加载统一在 `onMounted` 中触发，使用 `ref` 包裹响应式数组并通过 `v-loading` 展示加载态，错误通过 `ElMessage.error` 提示。
- 表单提交采用 try/catch 包裹 API 调用，成功时 `ElMessage.success` 并刷新数据，finally 中重置 loading 状态。
- 复杂表单使用 `reactive` 对象集中管理（如 `datasetForm`、`configForm`、`full` 多集合），新增/删除操作后通过 `markDirty()` 或手动标记未保存状态。
- UI 交互通过 Element Plus 的 `el-dialog`/`el-drawer` 承载编辑界面，并使用 `destroy-on-close` 避免状态残留。
