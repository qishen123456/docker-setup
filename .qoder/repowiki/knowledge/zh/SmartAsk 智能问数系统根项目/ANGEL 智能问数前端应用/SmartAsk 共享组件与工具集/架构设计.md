模块按职责划分为四个子目录：
- `components/smartask/`：SmartAsk 对话界面的一组 Vue SFC（ChatHeader、ComposerArea、LiveExecutionFeed、LogTimeline、PlanCard、ResultDigestCard、SqlBlock、ThinkingCard、TypewriterLine、UserBubble、WelcomeScreen），以及根级的 `SqlDebugFloat.vue` 悬浮调试入口，均通过 `<script setup>` + `defineProps`/`defineEmits`/`defineModel` 声明式 API。
- `composables/`：纯函数式组合式函数，`useOrgTree.js` 将 SQL 行数据与 report_config 构造成带层级、指标聚合、风险信号的组织树；`useSmartAskReportHistory.js` 封装历史快照的构建、去重签名、恢复与双写一致性逻辑，依赖外部注入的 session/messages/datasets 等回调。
- `utils/`：无状态工具函数，`datasetAutofillPromptMining.js` 从 Agent Prompt 中抽取 SQL 样例并去重，`feishu.js` 封装飞书内应用自动登录流程。
- `styles/angel-theme.css`：全局 CSS 变量主题，集中定义安吉尔品牌色板、Element Plus 变量映射、组件样式覆写与动画 keyframes，被所有组件通过 scoped style 引用。

依赖方向单向：components → composables/utils → styles；composables 不反向依赖组件，仅通过参数注入副作用（如 ElMessage、localStorage）。
