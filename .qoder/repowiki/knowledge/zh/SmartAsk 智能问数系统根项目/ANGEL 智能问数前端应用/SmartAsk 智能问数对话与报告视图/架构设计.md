模块以 `SmartAsk.vue` 为根视图，采用「左侧对话区 + 右侧执行详情面板」的双栏布局，通过 `featureAccess` 特性开关控制各子组件可见性。
- 视图层：`ChatHeader`、`ComposerArea`、`WelcomeScreen`、`UserBubble` 等组件负责头部、输入框、欢迎页与消息气泡；结果渲染由 `PlanCard`、`ThinkingCard`、`ResultDigestCard`、`SqlBlock`、`LiveExecutionFeed`、`LogTimeline` 等卡片/时间线组件组合而成。
- 状态层：`state/smartAskSession.js` 使用 `reactive` 维护单轮会话（question、status、result、logs、startedAt/updatedAt 等），并通过 localStorage 持久化轻量输入恢复；`state/smartAskHistory.js` 管理跨会话的历史报告列表，支持本地 compact + 服务端同步合并、按 scope（role:identity）隔离存储。
- 组合式逻辑：`composables/useSmartAskReportHistory.js` 暴露 `buildReportHistorySnapshot`、`saveCurrentToHistory`、`restoreHistory` 三个方法，负责将当前 session 快照化、去重签名、权限过滤后写入 history store，并支持从历史恢复时把最后一条 AI 的 data 强制对齐到完整 result。
- 数据流方向：SmartAsk.vue → 调用 session state 的 appendLog/replaceLogs 驱动 LogTimeline/LiveExecutionFeed 实时更新；用户发送通过 ComposerArea 触发 handleSend，经 API 流式回调更新 logs 与 result；历史记录通过 useSmartAskReportHistory 在结果完成时异步 upsert 到 smartAskHistory store。
- 依赖边界：组件仅通过 props/emits 通信，不直接访问 store；store 通过 `useSmartAskHistory()` 返回的函数被 composables 和视图注入；API 调用集中在 `../api/index.js`，模块内不直接发起 HTTP。
