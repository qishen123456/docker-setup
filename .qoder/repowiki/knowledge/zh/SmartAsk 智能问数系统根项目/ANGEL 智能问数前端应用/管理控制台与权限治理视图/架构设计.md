本模块由 5 个独立的 Vue 单文件组件构成，均位于 `frontend/src/views/` 下，作为路由级页面直接挂载到前端路由：
- `AdminConsole.vue` 是核心聚合页，通过 `activeConsoleTab` 在 dashboard / permissions / ask-flow / fields / data / logs 六个子面板间切换，每个子面板使用 `<template v-if>` 条件渲染，共享同一份 roles 定义和统一的 API 调用入口。
- `AIModels.vue`、`AgentManagement.vue`、`EmployeePermissions.vue`、`OrganizationTrees.vue` 各自独立负责一个管理域，采用左侧列表 + 右侧编辑器的典型双栏布局模式。
所有视图统一通过 `../api/index.js` 导入后端接口函数，并通过 `../state/featureFlags.js` 暴露的 `useFeatureFlags()` composable 获取 `isFeatureEnabled` 来控制按钮显隐与操作权限，形成“API 层 → feature flag → 视图”的单向依赖方向。各组件内部状态以 `ref` / `reactive` 管理，无跨组件共享 store，属于扁平化的页面级状态设计。
