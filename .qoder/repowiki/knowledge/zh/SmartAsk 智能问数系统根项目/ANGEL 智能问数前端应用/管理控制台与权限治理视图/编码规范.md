- 每个视图在 `onMounted` 钩子中先调用 `loadFeatureFlags()` 再加载业务数据，确保功能开关可用后再渲染受控 UI。
- 所有后端交互统一通过 `import { ... } from '../api/index.js'` 引入，不直接在组件内发起 HTTP 请求。
- UI 操作按钮通过 `v-if="isFeatureEnabled('xxx')"` 控制显隐，表单保存/删除等操作前用 `ElMessageBox.confirm` 二次确认危险操作。
- 表格类页面使用 `el-table` + `v-loading` 包裹数据区域，分页/筛选参数集中在 `ref` 对象中（如 `logFilters`、`bulkForm`），变更时触发重新查询。
- 组织树选择统一使用 `el-tree-select` 并配合 `check-strictly`、`node-key="id"`、`:props="{ label, value, children }"` 的标准配置模式。
- 组件内样式采用 `<style scoped>` 并以 `cs-`、`agent-`、`org-`、`permission-` 等命名空间前缀区分不同页面的 CSS 类名，避免全局污染。
