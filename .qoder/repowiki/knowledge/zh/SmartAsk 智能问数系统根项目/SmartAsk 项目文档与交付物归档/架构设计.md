本模块为纯文档仓库，按用途划分为两个子目录：`docs/` 存放面向用户与运维的部署手册（如 `SmartAsk_部署与交付手册.md`、`Linux_Docker部署运维手册.md`、`宝塔面板部署说明.md`）、产品方案与流程图（如 `基础问数流程.md`、`进阶问数流程.md`、`smartask-basic-flow-sketch.html`）、以及各类诊断与行动计划；`deliverables/` 存放阶段性交付产物，其中 `product-strategy/` 以 `overview.md` 作为总览入口，指向具体优化计划文件。所有文档以 Markdown 为主，辅以 HTML 流程图和 XML/PPT 大纲模板，无代码依赖，仅通过文件名与索引 README 组织检索。
