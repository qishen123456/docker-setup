本模块为纯数据与脚本目录，无 Python 包结构，所有文件以 JSON 明文形式被后端直接读取：
- 应用级配置：`app_config.json` 提供端口、调试开关、secret_key、chroma 路径等；`.secret_master_key` 作为主密钥。
- 数据源管理：`datasources.json`（主）与 `datasources.local.json`（本地覆盖）通过 `databases` 数组 + `next_id` 自增 ID 维护多数据库连接，支持 sqlite/postgresql 等类型，密码以 base64 存储。
- 功能开关与 RBAC：`feature_flags.json` 是核心开关引擎，每个 feature 包含 label/description/category/module/kind/order/enabled/roles/experimental/risk 字段，按 module 分组控制导航入口、按钮、流程等粒度；`rbac_permissions.json`、`employee_permissions.json`、`data_permissions.json`、`organization_trees.json` 分别承载角色-资源、员工-组织、数据集权限与组织树结构。
- AI 与提示词：`ai_settings.json`、`sql_prompts.json`、`ask_flow.json` 定义模型通道、SQL 生成提示词与问答流程。
- 集成与审计：`feishu_sync.json` 管理飞书表格同步任务；`auth_tokens.json`、`query_history.json`、`dataset_node_index.json`、`smartask_report_history.json` 记录认证令牌、查询历史、数据集索引与报告历史；`datasource_changes.log` 记录数据源变更日志。
- 测试与文档：`run_smartask_tests.py` 是从 Markdown 问题清单驱动端到端批量测试的脚本，调用 `/api/smart-chat` 并生成 JSON+MD 报告；`confirmed_behaviors_baseline.md`、`smartask_issue_analysis.md`、`smartask_test_question_list.md` 为测试用例与基线文档。
依赖方向单向：后端代码读取这些 JSON 文件，本模块不反向依赖任何 Python 模块。
