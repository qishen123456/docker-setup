- 所有公开函数与类方法均使用 `from __future__ import annotations` 启用 PEP 563 延迟求值，避免运行时导入开销。
- 对外暴露的统一返回结构包含 `need_confirm`、`confirm_question`、`options`、`auto_pick_option_id`、`reason` 五个字段，由 `_normalize` 集中规范化。
- 选项 ID 统一采用 `arbiter_dataset_{dataset_id}` 命名前缀，确保与前端交互稳定。
- 字符串比较前先通过 `_compact` 去除空白并转小写，保证中文业务词匹配的鲁棒性。
- LLM 交互通过注入的 `chat_json(system_prompt, user_prompt, fallback, trace, module, class_name)` 回调完成，而非直接 HTTP 调用。
