- 批量测试：`python backend/batch_test_questions.py` 输出 `/app/batch_test_results.json`，再运行 `python backend/analyze_batch_results.py` 生成 `_report.md`。
- Bookshelf 包迁移：`python backend/export_bookshelf_bundle.py [output.json]` 与 `python backend/import_bookshelf_bundle.py bundle.json`。
- 运行时配置：`python backend/export_runtime_config.py` / `import_runtime_config.py bundle.json [--force]`，覆盖路径由 `SMARTASK_CONFIG_DIR` 控制。
- 部署自检：`docker compose exec backend python verify_deployment.py` 或本地 `python backend/verify_deployment.py`。
- 密钥加密：`python backend/encrypt_env_secrets.py --file .env`。
- 消费者标准数据集：`python backend/create_consumer_standard_dataset.py`。
- 文档驱动重建：`python backend/regenerate_dataset_from_doc.py --dataset-id N --doc docs/xxx.md --dry-run|--apply http://host:5002`。
