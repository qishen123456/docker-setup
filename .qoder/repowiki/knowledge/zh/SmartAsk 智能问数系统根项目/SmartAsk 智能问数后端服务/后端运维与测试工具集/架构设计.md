本模块由一组相互独立的 Python 脚本组成，每个脚本承担单一职责并通过 `if __name__ == "__main__"` 暴露 CLI 入口，彼此之间无共享代码依赖。
- 数据迁移/同步类：`export_bookshelf_bundle.py` / `import_bookshelf_bundle.py`、`export_angel_group_data.py` / `import_angel_group_data.py`、`export_runtime_config.py` / `import_runtime_config.py` 成对出现，统一通过 `BookshelfRepository` 连接 PostgreSQL，使用 `psycopg2.extras.RealDictCursor` 读取 JSONB 字段，输出到 `backend/imports/*.json` 目录。
- 测试与评估类：`batch_test_questions.py`、`batch_test_consumer_questions.py`、`batch_test_ecommerce_questions.py` 调用 `ask_flow.ask_flow_controller.ask` 执行问数链路并写入 `/app/batch_test_results.json`；`single_test.py`、`consumer_single_test.py` 提供单题超时测试；`analyze_batch_results.py` 将结果转为 Markdown 报告。
- 数据集构建类：`create_consumer_standard_dataset.py` 直接通过 SQL 向 Bookshelf 表写入消费者标准数据集（含 LLD、数据字典、Golden SQL、Agent Prompt、Report Config）；`regenerate_dataset_from_doc.py` 基于 `dataset_copilot` 从 Markdown 文档生成 payload 并通过 `/api/bookshelves/datasets/<id>/full` 原子替换。
- 运维辅助类：`verify_deployment.py` 检查 PostgreSQL 连通性、关键表、HTTP 健康接口与报告契约；`encrypt_env_secrets.py` 就地加密 `.env` 中的敏感键；`update_syyb_profile_members.py` 从 `angel_group_data` 抽取维度成员更新 `data/dataset_dimension_profiles.json`；`agent_registry.py` 维护 `data/agent_registry.json` 中四个 Agent 的 system_prompt 与 knowledge_base。
- 依赖方向：所有脚本均只向上依赖 `bookshelf_repository`、`config_manager`、`ask_flow`、`dataset_copilot` 等上层模块，不反向被业务代码引用，属于纯工具层。
