- 所有对外 API 统一通过 `_require_super_admin()` 校验角色为 super_admin，失败返回 403 JSON 错误。
- 运行时包（bundle）采用固定 schema：包含 `version`、`type`、`exported_at`、`configs`、`bookshelf.tables`、`log_files`、`manifest` 字段，导出与导入均围绕该结构操作。
- 数据库写入使用 `SAVEPOINT smartask_runtime_import_row` 包裹单行 upsert，失败时回滚到 savepoint 并记录跳过原因，保证逐行容错。
- 自然键去重通过 `NATURAL_KEY_COLUMNS` 映射表名到列组合，配合 `DEDUP_ORDER_BY` 定义优先级，使用窗口函数 `ROW_NUMBER() OVER (PARTITION BY ...)` 实现幂等 upsert。
- 数据集引用统一通过 `DATASET_REFERENCE_TABLES` 白名单识别，并在导入前构建 `dataset_id_map` 将旧 id 映射到新 id，未匹配的记录以 `_skip_detail` 结构化记录跳过原因。
- SQL 变更脚本按 `YYYYMMDD_描述.sql` 命名存放在 `backend/migrations/`，运行时通过 `_ensure_optional_tables` 中的 `CREATE TABLE IF NOT EXISTS` 保证向后兼容。
