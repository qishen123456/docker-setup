模块由三层组成：
- `backend/runtime_migration.py` 是核心服务层，封装了运行时包（bundle）的导出（`export_runtime_bundle`）、导入（`import_runtime_bundle`）、预览（`preview_runtime_import`）、备份（`create_runtime_backup`/`list_runtime_backups`）以及状态汇总（`summarize_runtime_state`/`summarize_bundle`），通过 `BookshelfRepository` 访问 PostgreSQL，使用 `psycopg2.extras.RealDictCursor` 读取行记录，并借助 `SYSTEM_LOG_SCHEMA_SQL` 确保可选表存在。
- `backend/controllers/runtime_migration.py` 是 Flask Blueprint（`/api/runtime-migration`），仅做请求解析、权限校验（`_require_super_admin` 要求 role=super_admin）和响应包装，调用服务层函数。
- `backend/migrations/*.sql` 是按时间戳命名的幂等 DDL 脚本，用于 Bookshelf 表结构演进（如 `bookshelf_schema.sql`、`system_event_logs.sql`、`dataset_transforms.sql` 等），由 `_ensure_optional_tables` 在运行时按需执行 `CREATE TABLE IF NOT EXISTS` 保证兼容。
依赖方向单向：controller → runtime_migration → BookshelfRepository/psycopg2；migrations 为纯 SQL 资产，被服务层以字符串形式内联执行。
