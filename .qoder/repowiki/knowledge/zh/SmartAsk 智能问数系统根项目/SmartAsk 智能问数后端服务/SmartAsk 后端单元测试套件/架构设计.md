测试模块采用扁平结构，每个被测功能对应一个独立的 `test_*.py` 文件，全部基于 Python 标准库 `unittest.TestCase` 编写。所有测试文件通过 `sys.path.insert(0, ...)` 将 `backend/` 目录加入模块搜索路径，从而直接 import 同层源码（如 `four_agent_ask`、`disambiguation.scoring`、`ask_flow.controller`、`smartask_report_history_store` 等），无需安装依赖即可运行。`_punct_sql.py` 是辅助脚本而非测试用例，用于交互式验证 SQL 生成逻辑。测试按职责划分：安全与权限类（`test_security_guards.py`、`test_route_and_permission_guards.py`）通过 Flask `app.test_client()` 发起 HTTP 请求；业务逻辑类（`test_basic_dataset_confirmation_scoring.py`、`test_build_dataset_node_index.py`）直接调用函数并断言返回值；流程控制类（`test_ask_flow_controller.py`、`test_smartask_report_history_store.py`）使用 `unittest.mock.patch` 模拟外部依赖（如 `feature_flags.feature_available`、`history_store.read_json`）。
