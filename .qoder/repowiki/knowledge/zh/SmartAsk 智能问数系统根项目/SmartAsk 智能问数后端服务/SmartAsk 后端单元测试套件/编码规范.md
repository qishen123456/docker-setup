- 每个测试文件以 `test_` 前缀命名，内部定义继承自 `unittest.TestCase` 的测试类，方法名以 `test_` 开头描述具体场景。
- 所有测试文件在顶部通过 `sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))` 将 `backend/` 加入模块搜索路径，以便直接 import 同级源码。
- 对外部依赖（如 feature flags、JSON 读写、HTTP 客户端）统一使用 `unittest.mock.patch` 进行模拟，避免真实环境依赖。
- HTTP 接口测试通过 `app.test_client()` 构造客户端，并使用 `_request` 等私有辅助方法统一封装 GET/POST 请求与断言。
- 测试数据通过局部工厂函数（如 `_ctx`、`make_history_item`）构造，保持用例简洁且可复用。
