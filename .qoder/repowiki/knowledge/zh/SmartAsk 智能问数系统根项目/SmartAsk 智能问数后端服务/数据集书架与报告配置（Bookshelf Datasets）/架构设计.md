本模块由五个职责清晰的子文件组成，围绕 BookshelfRepository 提供的 PostgreSQL 持久层展开：
- `controllers/bookshelf.py`：Flask Blueprint 入口，暴露 `/api/bookshelves/*` REST 接口，负责权限校验（super_admin / feature_flag）、SQL 只读校验、LLD/DDL/Golden SQL/Agent Prompt 质量评估、通过 DatasetCopilot 调用大模型生成数据集 payload。
- `dataset_transform_service.py`：独立的 `DatasetTransformService` 类，封装从原始同步表到视图/物化视图/表的 SQL 转换任务，支持手动执行、飞书同步后自动触发、测试执行及执行历史回写。
- `dataset_report_config.py`：对 `bs_dataset_config` 表的轻量 CRUD，提供默认配置合并策略，驱动 Agent4 输出格式与前端报表渲染。
- `dataset_dimension_profiles.py`：从 `data/dataset_dimension_profiles.json` 加载维度画像，按别名/分组/复合别名规则解析用户问题中的实体提及，返回结构化意图。
- `build_dataset_node_index.py`：离线脚本，根据源表 SQL 抽取组织节点并生成 `config/dataset_node_index.json`，供上游路由使用。
依赖方向单向向下：controller → service/repository → psycopg2；各服务之间无相互导入，仅共享 BookshelfRepository 与 DataSourceRouter。
