- 所有数据库操作均通过 BookshelfRepository._connect() 或 get_default_datasource() 获取连接，并使用 with 语句确保连接关闭。
- 对外暴露的 API 统一在 try/except 中捕获异常，返回 `{"error": ...}` 结构并附带 HTTP 状态码。
- SQL 文本在进入数据库前必须经过只读校验（以 SELECT/WITH 开头、禁止分号、过滤危险关键字）。
- 用户输入标识符（表名/视图名/列名）统一通过正则 `_normalize_identifier` 或 `_slugify_*` 函数清洗后再拼接 SQL。
- 配置类模块（report_config、dimension_profiles）提供 `ensure_table` / `load_*` 惰性初始化，并在异常时降级返回空结果而非抛错。
- 异步或耗时操作（如 AI 生成、SQL 执行）通过 `_log_dataset_prompt_event` / `log_event` 记录 category + event_type + details 的结构化日志。
