模块按 Flask Blueprint 分层：`controllers/auth.py`、`controllers/rbac.py`、`controllers/data_permissions.py`、`controllers/organization_trees.py` 分别暴露 `/api/auth/*`、`/api/admin/rbac/*`、`/api/admin/data-permissions/*`、`/api/admin/organization-trees/*` 路由；每个 controller 仅做参数校验、鉴权（`_require_super_admin` / `_require_feature`）和日志记录，业务逻辑委托给同目录下的 `*_store.py`。

存储层采用 JSON 文件持久化：`auth_store.py` 维护 `auth_tokens.json`（会话令牌+过期时间），`rbac_store.py` 维护 `rbac_permissions.json`（内置角色+自定义角色+分组），`data_permission_store.py` 维护 `data_permissions.json`（数据集访问规则），`organization_tree_store.py` 维护 `organization_trees.json`（多类型组织树节点）。所有 store 通过 `config_manager.read_json/write_json` 读写，并通过 `feature_flags` 动态注入可用功能键。

鉴权链路：请求经 `X-Auth-Token` 或 Session 由 `auth_store.get_current_user` 解析并刷新员工信息，再经 `rbac_store.effective_permissions` 合并 legacy role、直接分配 role_ids、分组继承得到最终 function/resource 权限；数据行级过滤由 `data_permission_store.apply_row_level_filter` 生成 SQL WHERE 子句，结合组织树编码/名称匹配实现。
