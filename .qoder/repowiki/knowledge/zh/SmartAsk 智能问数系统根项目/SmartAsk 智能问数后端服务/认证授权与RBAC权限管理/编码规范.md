- 每个 controller 以 `_require_super_admin()` 或 `_require_feature(key, error_text)` 作为统一鉴权守卫，失败时返回 `{success: False, error: ...}` 403 响应。
- 所有输入字段通过 `_as_text`/`_as_list`/`_as_int` 等清洗函数进行规范化，避免脏数据进入持久层。
- 敏感操作通过 `system_log_store.log_event(category=..., event_type=..., user=user, request_info=request_snapshot(request), status_code=...)` 记录审计日志。
- JSON 文件读写统一走 `config_manager.read_json/write_json`，并在读取失败时回退到空结构或默认值，保证健壮性。
- 角色与权限常量集中定义（如 `ROLE_LABELS`、`LEVEL_LABELS`、`RESOURCE_LEVELS`、`BUILTIN_ROLE_IDS`），控制器不硬编码中文标签。
- 对外接口统一返回 `{success: True/False, ...}` 结构，错误路径附带 HTTP 状态码。
