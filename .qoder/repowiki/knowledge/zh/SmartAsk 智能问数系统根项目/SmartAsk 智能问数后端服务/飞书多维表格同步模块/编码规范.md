- 所有 API 路由统一通过 _require_feature(key, error_text) 包装 require_feature 进行权限拦截，错误返回格式保持一致的 {error: ...} 结构。
- 异常处理采用 try/except 包裹业务逻辑，统一返回 {success: False, error: str} 或 {error: str} 的 JSON 响应，避免异常泄漏到客户端。
- 飞书 OpenAPI 调用统一通过 write_log(config_id, level, message) 记录 INFO/SUCCESS/ERROR 级别日志，并附带敏感信息脱敏（如 app_id[:10]...）。
- SQL 语句全部使用 psycopg2.sql.SQL 配合 sql.Identifier 动态拼接表名/列名，防止 SQL 注入。
- 配置读取区分 read_feishu_config（应用 .env 覆盖）与 read_feishu_config_raw（原始内容用于写入），保证展示与持久化语义分离。
- 目标表名通过 normalize_table_name 统一清洗为小写、下划线分隔、最长 60 字符的安全标识符，数字开头自动加 t_ 前缀。
