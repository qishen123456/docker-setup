本模块由四个职责清晰的 Python 文件组成，形成「引导 → 应用 → 配置 → 加密」的单向依赖链：
- `bootstrap.py` 是容器/本地的一次性引导脚本，按顺序执行 PostgreSQL 连通等待、SQL 迁移（`backend/migrations/*.sql`）、运行时配置恢复（`imports/runtime_config_bundle.json`）、首次 bundle 导入（bookshelf/angel_group_data）、内置数据集模板同步，最后通过 `os.execv` 替换进程为 `app.py`。
- `app.py` 是 Flask 应用主入口，加载 `.env` / `.env.local`，注册全部 `controllers/*_bp` 蓝图，配置 CORS、错误处理器、健康检查 `/api/health`，并通过 `before_request`/`after_request` 钩子统一记录 API 访问日志到 `system_log_store`。**重要**：在 `if __name__ == "__main__"` 块中启动飞书同步调度器的后台守护线程（见下方「飞书同步调度器集成」）。
- `config_manager.py` 集中管理 `config/` 目录下的 JSON 配置文件（`app_config.json`、`datasources.json`、`ai_settings.json`、`query_history.json`），提供读写、默认模板初始化、`.local` 文件覆盖机制、环境变量覆盖（`SMARTASK_DB_*`、`SMARTASK_AI_*`、`SMARTASK_FEISHU_*` 等前缀）以及 Base64/enc:v1 密文的编解码。
- `secret_codec.py` 实现基于 HMAC-SHA256 + XOR 流密码的轻量级敏感值加密，密钥从 `SMARTASK_SECRET_MASTER_KEY` 或 `config/.secret_master_key` 读取，支持命令行 `encrypt|decrypt` 子命令。

### 飞书同步调度器集成（2026-08-07 新增）

**设计决策**：飞书同步调度器需要在 Flask 进程内持续运行定时任务，但不能阻塞主线程处理 HTTP 请求。

**实现方案**（[app.py](file:///backend/app.py)）：
```python
import threading

def _start_feishu_sync_scheduler():
    """后台守护线程启动飞书同步调度器"""
    try:
        from feishu_sync_service import sync_service
        print("启动飞书同步调度器后台线程...")
        sync_service.start_scheduler()  # 阻塞调用，在独立线程中运行
    except Exception as e:
        print(f"飞书同步调度器启动失败: {e}")
        import traceback
        traceback.print_exc()

if __name__ == "__main__":
    # 启动飞书同步后台调度线程（守护线程，随Flask进程退出）
    feishu_sync_thread = threading.Thread(
        target=_start_feishu_sync_scheduler,
        daemon=True  # 关键：设置为守护线程
    )
    feishu_sync_thread.start()
    
    # 启动Flask主线程
    app.run(host="0.0.0.0", port=BACKEND_PORT, debug=False, use_reloader=False)
```

**关键特性**：
- **非阻塞设计**：使用 `daemon=True` 守护线程，Flask 主线程立即返回处理请求
- **生命周期绑定**：守护线程随 Flask 进程退出自动终止，无需手动清理
- **异常隔离**：调度器启动失败不影响 Flask 服务启动，仅打印错误日志
- **Docker兼容**：容器内通过 `python bootstrap.py` → `os.execv(app.py)` 自动执行

**验证方式**：
```bash
# 查看日志确认启动成功
docker logs smartask-backend | grep "飞书同步调度器"

# 手动触发同步测试
curl -X POST http://localhost:5002/api/feishu-sync/{config_id}/start \
  -H "X-Auth-Token: {token}"
```

依赖方向：`app.py` → `config_manager` / `secret_codec`；`bootstrap.py` → `config_manager` / `secret_codec`；`config_manager.py` → `secret_codec.py`；各模块不反向依赖。
