- 所有管理员接口统一通过 `_require_super_admin()` 校验用户角色，非 super_admin 返回 403 并附带中文错误消息。
- HTTP 响应统一包装为 `{success: bool, ...}` 结构，异常分支返回 `{success: False, error: str}` 并设置对应 HTTP 状态码。
- 日志写入采用 try/except 包裹 psycopg2 操作，失败时调用 `_fallback_write` 降级到 JSONL 文件，保证记录不丢失。
- 字符串字段统一通过 `_truncate(value, limit)` 截断，JSON 字段通过 `_json_safe(value, depth)` 递归序列化并限制深度与长度。
- Feature Flag 条目遵循固定 schema：包含 label、description、category、module、module_label、kind、order、enabled、roles、experimental 等字段，并按 module 分组维护。
