本模块以 `backend/controllers/advanced_capabilities.py` 中的 `advanced_capabilities_bp`（`/api/admin/advanced-capabilities`）作为唯一 HTTP 入口，所有路由均经 `_require_admin()` 校验 super_admin/admin 角色后，委托 `smartask_advanced.config_store` 完成配置的加载、保存、导入与重置，并通过 `smartask_advanced.registry.capability_summary` 生成结构化摘要。
- 运行时编排由 `smartask_advanced.service.AdvancedAskService` 驱动：按 config_store 中的技能清单依次执行 route_guard → asset_pack → planner → sql_quality → conclusion_advice 等技能链，失败时回退到 `smartask_basic.service.BasicAskService`。
- 两个子包职责分离：`smartask_advanced` 提供可插拔技能注册表与执行计划，`smartask_basic` 提供基础 SQL 解析能力；控制器层仅负责权限与配置持久化，不感知具体技能实现。
