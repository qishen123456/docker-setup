- 每个 Skill 以类形式定义，包含静态 `key` 属性和实例/静态 `run()` 方法作为统一入口，便于上层按 key 动态调度。
- 所有输入输出采用纯 Python 原生类型（Dict[str, Any]、List[Dict]），不直接依赖 ORM 或框架对象，保证可测试性与可移植性。
- 对外部可选依赖（如 pandas）采用 try/except 导入并在运行时判断是否存在，缺失时走降级逻辑而非抛出异常。
- 字符串匹配与解析统一使用预编译的正则表达式常量（如 DANGEROUS_PATTERN、FIELD_PATTERN、TABLE_PATTERN），避免重复构造。
- 数值处理统一通过 `number_value()` 工具函数安全转换，空值或缺失字段被过滤后再参与计算。
