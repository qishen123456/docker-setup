- 每个 Skill 类以 `key = "xxx"` 字符串标识自身，并通过 `run` 方法返回统一结构的 Dict，便于上层按 key 注册与分发。
- 文本处理统一使用 `_compact` 静态方法去除空白并转小写，再配合 `re.search` / `in` 进行中文关键词匹配。
- 数值型 ID 列表统一通过 `.common.as_int_list` 或内部 `_unique_int` 工具函数清洗去重，避免脏数据进入下游逻辑。
- 对外部依赖（repository、OrganizationRouteResolver）通过构造函数注入，Skill 本身保持无状态或仅持有引用。
- 评分/决策逻辑采用多阶段短路策略：高置信度分支直接 return，低置信度分支累积 warnings 并降级为 needs_confirmation。
