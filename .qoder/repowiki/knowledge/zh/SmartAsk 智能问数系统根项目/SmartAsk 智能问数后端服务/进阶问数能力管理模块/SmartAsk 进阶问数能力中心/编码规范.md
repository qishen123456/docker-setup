- 每个技能以独立类实现，统一提供 run(...) 或静态 infer/run 方法，被 service 通过 if self._has_skill(skills, key) 条件分支调用。
- 所有中间状态通过 context dict 传递（trace_id/skills/candidates/assets/route_guard/intent/enabled_map），而非全局变量。
- trace 事件统一通过 _emit 封装，包含 time/stage/status/title/summary/detailLines/thought/toolType/duration_seconds 字段，错误时静默吞异常。
- 配置项一律经 _clean_bool/_clean_int/_normalize_* 等清洗函数归一化，禁止直接使用原始 JSON 值。
- 内置 skill key 集合 DEFAULT_SKILL_KEYS 用于区分内置与自定义技能，自定义技能通过 import_skills 导入且不允许覆盖内置 key。
