本模块由三个独立的 Skill 类组成，每个类通过 `key` 属性标识自身并暴露统一的 `run()` 入口，供上层技能调度器按 key 分发调用：
- `pandas_analyze.py` 中的 `PandasAnalyzeSkill`：读取 `dataset_results` 中的 rows，自动识别标签列（组织路径/名称等）、达成率、任务量、实际完成、缺口等语义列，支持按 `targetLevel` 聚合分组后做 top/bottom 排名，并生成自然语言 summary；pandas 未安装时回退到纯 Python 模式。
- `golden_sql.py` 中的 `GoldenSqlSkill`：从 `contexts` 中收集各 dataset 的 `golden_sql_samples`，按 `match_score` 和 `quality_score` 降序排序，返回 top5 样本及最佳样本。
- `sql_quality.py` 中的 `SqlQualitySkill`：对每个 dataset 的 SQL 执行只读检查（正则过滤危险关键字）、Agent3 复核状态检查、字段与表名与数据字典/Schema 的映射校验，累计扣分得到 0-100 分数并汇总 warnings。
三者均依赖同目录 `common` 模块提供的 `compact_row`、`first_present`、`number_value`、`to_jsonable` 等工具函数，保持输入输出均为纯 Dict/List 结构，无外部状态。
