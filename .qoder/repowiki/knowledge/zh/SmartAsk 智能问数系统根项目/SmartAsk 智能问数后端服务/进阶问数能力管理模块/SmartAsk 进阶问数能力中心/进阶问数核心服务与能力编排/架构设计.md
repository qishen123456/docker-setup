模块由三层构成：
- 配置层 `config_store.py`：定义 `DEFAULT_SKILLS`、`DEFAULT_ADVANCED_CAPABILITIES` 常量，通过 `_merge_skills`/`normalize_config` 将用户 JSON 与默认值合并，持久化到 `advanced_capabilities.json`，并提供 `load_config`、`save_config`、`import_skills`、`reset_config`、`enabled_skills` 等 API。
- 注册层 `registry.py`：仅暴露 `build_skill_plan` 和 `capability_summary` 两个函数，从配置中抽取已启用的技能列表及摘要，供上层按确定性顺序消费。
- 服务层 `service.py`：`AdvancedAskService` 类持有 `fallback_service`（默认 `basic_ask_service`），通过 `_run_advanced_trace` 按 `skills` 顺序串联 dataset_route → route_guard → asset_pack → planner → golden_sql → 自定义 Skill → 外部工具声明 → handoff；结果回传后通过 `_run_result_trace` 追加 sql_quality、template_policy、self_check、answer_contract、conclusion_advice、evidence_vote 等后置阶段。所有阶段通过统一的 `_emit` 方法以 `{type: 'trace', entry: 'advanced.ask', event: {...}}` 格式回调，支持 `live_callback` 实时追踪。
依赖方向单向：service → registry → config_store，skill 实现来自同级 `skills` 包，不反向依赖 service。
