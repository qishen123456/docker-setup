- 所有容器间通信通过 docker-compose 网络与端口映射暴露，服务间依赖通过 depends_on + healthcheck condition 声明，禁止硬编码 IP。
- 环境变量统一以 SMARTASK_ 前缀命名，敏感值经 enc:v1 加密存储于 .env 或 config/*.json，并通过 config/.secret_master_key 或 SMARTASK_SECRET_MASTER_KEY 解密。
- 数据库初始化脚本按字母序放入 docker/postgres/init 目录，升级脚本放在 backend/migrations/ 目录，确保幂等与可重放。
- 部署脚本遵循 set -euo pipefail 风格，使用 info/warn/fail 统一日志输出，关键步骤带进度条与失败诊断信息收集。
- 跨平台脚本成对提供 .sh 与 .ps1/.bat 版本，保持参数语义一致，由 README 中统一命令索引引用。
