根目录作为编排与交付层，将子模块串联为可独立运行的微服务栈：
- docker-compose.yml 定义 postgres（Alpine + initdb.d 按序执行 SQL）、backend（Flask 应用，依赖健康检查后启动）、frontend（Nginx 托管 Vue 静态资源，反代 /api 到后端）三个服务，并通过 volumes 持久化 pg_data、chroma_db、config、backups、logs。
- deploy.sh（Linux）与 deploy.ps1/bat（Windows）是统一入口，依次完成 Docker 环境检查、APT/Docker 镜像源配置、.env 必填项与 enc:v1 密文主密钥校验、docker compose up --build、后端健康等待、容器内 verify_deployment.py 自检、可选 integration_test.py 集成测试。
- backend/bootstrap.py 在容器启动时串行执行：等 DB → 运行 migrations/*.sql → 首次导入 imports/* bundle → 启动 Flask；config_and_data 中的 JSON 配置文件通过 bind mount 挂载到 /app/config，运行时变更由后端写回。
- infra_postgres_init 的 SQL 脚本通过 ./docker/postgres/init 卷注入，仅首次空库时按字母序执行，保证 schema 与业务数据初始化顺序可控。
- scripts/ 与 tools/ 提供跨模块辅助能力：backup_all.py、verify_deployment.py、integration_test.py 在容器内或宿主机驱动运维流程；convert_pdfs_to_md.py、create_phase1_dataset.py 用于数据准备。
- agents_skills 与 workbuddy_memory 作为知识沉淀层，不直接参与运行时，但为 AI Agent 技能与长期记忆提供上下文。
