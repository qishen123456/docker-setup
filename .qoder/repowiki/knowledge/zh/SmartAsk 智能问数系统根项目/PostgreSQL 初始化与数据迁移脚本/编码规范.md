- 每个迁移文件以三位数字前缀（001_、002_…）命名，确保容器启动时按预期顺序执行。
- 所有 DDL 操作包裹在 BEGIN/COMMIT 事务中，保证原子性。
- 表结构变更统一使用 CREATE TABLE IF NOT EXISTS，配合 ON CONFLICT DO NOTHING 实现幂等初始化。
- 所有业务表通过 dataset_id 外键关联 bs_datasets(id) 并设置 ON DELETE CASCADE，实现数据集级数据隔离与级联删除。
- 时间字段统一使用 TIMESTAMPTZ 类型，默认值 NOW()，审计字段包含 created_at/updated_at。
- 可变数据结构统一采用 JSONB 类型并配合 DEFAULT '{}'::jsonb 或 '[]'::jsonb 空值保护。
- 查询性能优化通过在常用过滤列（is_active、dataset_id、created_at）上建立复合索引。
