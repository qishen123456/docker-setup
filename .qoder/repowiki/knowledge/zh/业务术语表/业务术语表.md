### 4-Agent 协作架构
- 定义：SmartAsk 的核心架构模式，包含四个专业 Agent：Agent1 路由中枢（意图识别、数据集匹配）、Agent2 SQL 架构师（生成只读 PG SQL）、Agent3 合规审计员（复核 SQL 安全性）、Agent4 业务分析官（输出高管视角分析报告）。四个 Agent 按顺序协作完成从自然语言到可执行 SQL 再到分析报告的完整流程。
- 别名：四智能体、four-agent、agent-collaboration

### ReportSpec v2
- 定义：SmartAsk 的动态报告规范版本 2，定义了标准化的报告数据结构契约，确保不同 Agent 生成的报告格式一致。ReportSpec v2 支持动态报告生成、路由可信度说明、低相似命中确认等功能，是前后端交互的标准数据格式。
- 别名：report-spec、report-schema、v2-report

### 行级权限
- 定义：SmartAsk 的四层权限体系中的第四层，通过组织树交集注入 WHERE 条件实现数据行级别的访问控制。当用户查询涉及特定组织范围时，系统自动在 SQL 中添加相应的过滤条件，确保用户只能看到其权限范围内的数据。
- 别名：row-level-security、org-permission、data-permission

### 数据集书架
- 定义：SmartAsk 中用于管理和组织数据集的虚拟书架概念，每个数据集包含 DDL、LLD、字段字典、Golden SQL、Agent Prompt 等完整元数据。支持通过提示词自动生成数据集结构，是 NL2SQL 能力的核心数据源。
- 别名：bookshelf、dataset-bookshelf、data-source

### 运行态配置
- 定义：SmartAsk 的运行时配置文件集合，包括 feature_flags.json、datasources.json、ai_models.json 等 JSON 文件，支持通过 bundle 形式进行环境间迁移。配置即代码的设计理念使得新增数据集无需修改代码，通过配置即可扩展功能。
- 别名：runtime-config、config-bundle、dynamic-config

### SKILL 体系
- 定义：SmartAsk 项目中将排障经验和运维 SOP 沉淀成 AI 可读的技能文档，位于 .agents/skills/ 目录下。每个 SKILL.md 文件定义特定的业务能力或操作流程，如全局约束、排名调试、飞书同步操作等，避免每次重新推理相同问题。
- 别名：skills、agent-skills、knowledge-base

### 节点索引
- 定义：config/dataset_node_index.json 文件中维护的真实节点、层级、别名、叶子的事实底座，是 SmartAsk 中组织解析和数据集匹配的核心数据源。优先级高于旧的 dataset_dimension_profiles.json 语义画像，后者仅用于别名增强。
- 别名：node-index、dataset-index、organization-tree

### 黄金 SQL
- 定义：Golden SQL 是预定义的优质 SQL 模板，用于快速响应常见查询场景。当用户问题与黄金 SQL 匹配度高时，系统直接返回结果而无需经过完整的 LLM 处理流程，显著提升响应速度和准确性。
- 别名：golden-sql、template-sql、optimized-query

### 歧义仲裁
- 定义：DisambiguationArbiter 模块负责处理用户意图识别中的歧义情况，当多个数据集候选的置信度接近时（top≥80 且 margin≥20 直选；margin<15 或 runner-up≥55 触发确认），主动触发老板确认机制让用户选择正确的数据集。
- 别名：disambiguation、ambiguity-resolution、intent-arbiter

### SSE 流式交互
- 定义：Server-Sent Events 技术实现的实时数据推送机制，前端通过 sendSmartChatStream 发送请求，后端以 trace/report/message/done/error 事件流形式返回处理进度和结果。支持长时间运行的问数任务，用户体验流畅。
- 别名：sse-streaming、real-time-events、streaming-response
