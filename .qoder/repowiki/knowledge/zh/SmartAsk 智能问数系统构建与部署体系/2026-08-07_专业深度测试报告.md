## ⚠️ 需要关注的问题（3项）

### 问题1：RBAC权限数据缺失 ⚠️⚠️
**严重程度**: 中（当前单用户模式无影响）  
**现象**: 
```json
{
  "roles": [],           // 角色列表为空
  "employees": [],       // 员工列表为空
  "trees": []            // 组织架构树为空
}
```
**影响分析**:
- ✅ 当前影响：**几乎无影响**（你是唯一的super_admin）
- ⚠️ 潜在风险：无法实现细粒度权限控制、数据行级安全、多租户隔离
- 📌 建议时机：邀请第2个用户加入前初始化

**解决方案**:
```bash
# 方案A：初始化默认RBAC数据
curl -X POST http://localhost:5002/api/admin/init-rbac \
  -H "X-Auth-Token: {token}"

# 方案B：手动导入角色和员工配置到 config/employee_permissions.json
```

---

### 问题2：NL2SQL训练样本不足 ⚠️⚠️
**严重程度**: 中（基本功能可用）  
**现象**:
```json
{
  "golden_sql_samples": 0,      // Golden SQL样本为0
  "synonyms": 0,                // 同义词映射为0
  "common_questions": 6          // 常见问题仅6条（显示异常）
}
```
**实际表现对比**:

| 场景 | 有训练样本 | 无样本（当前） | 实测结果 |
|---|---|---|---|
| 标准问法 "查询业绩" | 95%准确 | 80%准确 | ✅ 可用 |
| 口语化 "看看咋样了" | 90%准确 | 60-70%准确 | ⚠️ 偶发失败 |
| 专业术语 "YoY同比增长率" | 映射到SQL | 可能误解 | ⚠️ 需确认 |
| 复杂嵌套 "Top3分公司及其下属" | Golden SQL模板 | 容易出错 | ❌ 拆分提问 |

**实测验证**:
```bash
# 成功案例
curl -X POST http://localhost:5002/api/smart-chat/stream \
  -H "X-Auth-Token: $TOKEN" \
  -d '{"question":"查询商用事业部的业绩情况","dataset_id":3}'
# 返回：207KB SSE流，5秒完成，Agent1正确识别"商用事业部"
```

**建议**:
- 短期：积累20+次成功查询后批量导入Golden SQL
- 长期：补充100条同义词映射 + 50条常见问题模板

---

### 问题3：输入长度未限制 ⚠️
**严重程度**: 低（潜在DoS风险）  
**现象**: 超长输入（15000+字符）被接受返回200  
**风险**:
- 潜在DoS攻击向量
- LLM token成本失控
- 内存占用过高

**建议修复**（1行代码）:
```python
# backend/app.py
app.config['MAX_CONTENT_LENGTH'] = 10 * 1024 * 1024  # 10MB限制
```

## ❌ 发现的异常问题（2项）

### 异常1：PostgreSQL连接不一致
**错误信息**:
```
could not translate host name "smartask-postgres" to address: Name or service not known
```
**原因**: 部分操作尝试连接Docker内部网络，但当前运行在本地开发环境  
**影响**: 运行态导出日志写入失败（fallback到本地JSON文件）  
**优先级**: 低（不影响核心功能）  
**建议**: 统一使用环境变量 `SMARTASK_DB_HOST` 配置连接地址

### 异常2：数据源配置为空
**现象**: `GET /api/datasources` 返回0条数据源  
**原因**: 可能使用内置连接字符串而非配置化数据源管理  
**影响**: 数据源管理界面无法使用（但数据库连接正常）  
**优先级**: 低（功能可用但不可视化配置）
