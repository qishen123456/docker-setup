# 前端像素级校验清单（五源对齐法）

> 基于 mvp-dev-expert-team 五源对齐法 + senior-developer 质量标准。
> 前端实现后、QA 测试前执行。

## 五源对齐

| 源 | 内容 | 校验方式 |
|---|---|---|
| 设计变量 | Design Token 定义 | 代码中 CSS 变量与 Token 定义逐项比对 |
| 设计元数据 | 组件规范（状态/尺寸/间距） | 代码实现的变体与规范比对 |
| 设计截图 | 原始设计稿 | 视觉比对 |
| AI 代码 | 实现的组件代码 | 逐组件检查 |
| 渲染截图 | 实际渲染效果 | 截图与设计稿叠加比对 |

**对齐标准**：色彩、间距、字号、圆角、阴影 5 个维度逐项核对，不允许"差不多"。

## 性能基准（Premium 标准）

- [ ] 首屏加载 < 1.5s
- [ ] 动画 60fps（无明显卡顿）
- [ ] 代码分割（首屏不含非必要 JS）
- [ ] 图片懒加载 + 合适格式
- [ ] 字体加载不阻塞渲染

## 交互状态完整性

每个组件必须覆盖 7 种状态：
- [ ] 默认
- [ ] 悬停
- [ ] 激活
- [ ] 禁用
- [ ] 加载中
- [ ] 错误
- [ ] 空数据

## 响应式

- [ ] 移动端断点行为已实现
- [ ] 平板端断点行为已实现
- [ ] 桌面端断点行为已实现
- [ ] 横竖屏切换无破坏

## 可访问性

- [ ] 正文对比度 ≥ 4.5:1
- [ ] 所有交互元素键盘可达
- [ ] 焦点可见
- [ ] 表单控件有关联 label
- [ ] 图片有 alt，图标按钮有 aria-label
