# SmartAsk 产品手册（HTML 演示版）— 交付说明

## 交付物

| 文件 | 说明 |
| --- | --- |
| `deliverables/SmartAsk_商业化推广报告.html` | 单文件 HTML 演示页，双击即可在浏览器打开。固定 1920×1080 舞台等比缩放适配任意屏幕，14 页左右翻页 |

## 形态（v5 · 横版翻页 + 专业报告风）

- **16:9 固定舞台**：1920×1080 设计画布，等比缩放居中适配任意视口，版式恒定
- **视觉风格**：浅灰画布 + 白卡片 + 柔和阴影的专业报告质感；深色仅用于封面、焦点大卡（口径确认防线 / 效率价值）与结尾页
- **翻页导航（五通道）**：置顶标签栏（**10 个章节**：概述/市场/痛点/能力/可信/场景/客户/价值/优势/交付，章节覆盖多页时范围内保持高亮，点击跳到章节首页）；底部玻璃圆点条（14 页页面级，hover 显示页名）；两侧箭头；**舞台左右边缘热区**；键盘 ← → / 空格 / Home·End；**鼠标滚轮翻页**（650ms 节流）；触屏滑动
- **行业数据图表（内联 SVG，零依赖）**：中国 BI 软件市场规模柱状图（10.7 / 13.2 / 17.8 亿美元，2026E 虚线预测样式，IDC）、自然语言交互类占比环形图（32%）、ABI 平台采用率对比条（29% → 50%+，Gartner），全部标注来源
- **字体**：全站统一 Noto Sans SC（思源黑体，中英数混排协调）；等宽字体仅保留在三处代码语义场景（封面问数终端演示卡、Agent 函数名、口径阈值表达式）
- **URL 直达**：`#3` 即打开第 3 页；已加 `Cache-Control: no-cache` 防缓存
- **内联编辑**：按 `E` 进入编辑模式（界面不显示入口按钮），标题与正文可直接修改，`E`/`ESC` 退出
- **动效**：翻页淡入横移、页内元素错峰进入、指标条滚动填充；遵循 `prefers-reduced-motion` 自动降级
- **结尾页**：左侧邀请 + 产品参数（2×2），右侧 POC 四周节奏卡，底部 POC 三要素横排
- **目标用户页**：左右两列统一为同一种卡片结构（标题+角色标签 / 描述 / 底部权限或价值行），节奏一致
- **交付部署页**：三阶段时间轴 + 容器启动依赖链（PG 健康等待 → migrate 自动迁移 8 个 schema → backend 启动 → frontend 托管，来自真实 docker-compose 依赖链）+ 部署/数据源/治理三卡垂直居中 + 能力边界贴底

## 演进记录

- v1 长滚动报告 → v2 Bento 错落网格 + 科技风 → v3 深色幻灯片 → v4 饱满化（67 处内容增补）→ v5 横版翻页骨架 + 浅色报告皮肤 + 行业图表 + 置顶标签栏 + 滚轮翻页 → v6 标签收敛为 10 章节 + 隐藏编辑入口 + 结尾页充实 → v7 全站字体统一 Noto Sans SC + 目标用户页双列卡片同构 → **v8 交付页垂直重排 + 新增容器依赖链**
- 修复记录：编辑提示条 translateY 不足常显（-70px → -140px）；P5/P2 中部大空白（内容垂直居中）；编辑按钮 `display:none` 被同规则内的 `display:grid` 覆盖（同规则后声明胜出）；P13 下半部空白（补依赖链 + 三卡居中 + note 贴底）
