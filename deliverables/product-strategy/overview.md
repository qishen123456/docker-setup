## 一句话结论
产品设计方向正确、权限体系部分领先，但工程实现欠账明显：50 问基线通过率仅 ~38%，存在 SQL 沙箱可绕过、匿名接口、XSS、弱密码等安全敞口，生产仍跑 Flask 开发服务器。

## 优化方案
- **15 条需求 / 94 人日 / 三阶段 16 周**（1.5 人配置）
- P0 信任底线（29d）：SQL 沙箱、XSS、密码、鉴权、同步调度、eval 门禁 → 第 1-4 周封闭
- P1 债务止血（36d）：gunicorn+连接池、JSON 迁 PG、双轨收敛、核心文件拆分（10748 行 → Query Contract 先行切 3 片）
- P2 体验与预埋（29d）：SSE 流式、指标语义层 v1、答案级 provenance
- 护栏：OPT-06 评测回归门禁先行于一切重构；第 1 周先上 4 项基线指标看板
