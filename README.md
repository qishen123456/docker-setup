## 快速开始

### 后端启动
```bash
cd backend
python app.py
```

### 前端启动
```bash
cd frontend
npm run dev
```

## 技术栈
- **后端**: Flask + Pydantic + SQLAlchemy
- **前端**: Vue 3 + Element Plus + Vite
- **AI**: OpenAI API + Vanna
- **数据库**: SQLite/MySQL/PostgreSQL
